# Полигон — продуктовая школа-симулятор

Учебный проект ВШЭ, курс «Основы инженерии цифровых продуктов» (2026). MVP образовательного продукта для изучения продуктового менеджмента: кандидат на junior-PM ведёт сервис «Накопления на цель» вымышленного банка «Кварц» через два связанных эпизода, получает разбор по критериям и решает самостоятельную задачу, которую видит продуктовый эксперт банка.

Демо: https://nominalnominalovich.github.io/polygon/ — вход без регистрации, прогресс хранится в браузере. Кнопка «Материалы защиты» открывает концепцию, отчёт и презентацию.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/polygon/
npm test         # контрольные прохождения симуляции
npm run build
```

## Устройство

- `src/sim/scenario.ts` — учебный мир: сегменты, источники, инициативы, правила эффектов.
- `src/sim/engine.ts` — детерминированный расчёт последствий; `engine.test.ts` — контрольные ветки.
- `src/sim/debrief.ts` — разбор по критериям К1–К6.
- `src/sim/trace.ts` — цепочки обоснования Г → П → И → Ф → Э для режима обоснования.
- `src/content/defense.md` — материалы защиты.

Стек: React 19, TypeScript, Vite, VKUI. Бэкенда нет: MVP статический, состояние в localStorage.

Банк «Кварц», люди и данные вымышлены.
